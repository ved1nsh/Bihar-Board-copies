Find the acute angle between the line $\dfrac{x}{1}=\dfrac{y}{3}=\dfrac{z}{0}$ and the plane $2x + y = 5$.
Ans

Direction vector of the line: $\vec d = (1,3,0)$.

Normal to the plane: $\vec n = (2,1,0)$.

If $\theta$ is the angle between line and plane, $\sin\theta = \dfrac{|\vec d\cdot\vec n|}{|\vec d||\vec n|}$.

$\vec d\cdot\vec n = 2 + 3 + 0 = 5$.

$|\vec d| = \sqrt{10},\ |\vec n| = \sqrt{5}$.

$\sin\theta = \dfrac{5}{\sqrt{10}\cdot\sqrt{5}} = \dfrac{5}{\sqrt{50}} = \dfrac{1}{\sqrt 2}$.

$\therefore \theta = 45^\circ = \pi/4$.

A speaks truth in $75\%$ of cases and B in $80\%$ of cases. In what percentage of cases are they likely to contradict each other on the same fact?
Ans

Let $T_A$ = A speaks truth, $L_A$ = A lies; similarly for B.

$P(T_A) = 0.75,\ P(L_A) = 0.25;\ P(T_B) = 0.80,\ P(L_B) = 0.20$.

Contradiction happens when one tells the truth and the other lies:

$P(\text{contradict}) = P(T_A)\cdot P(L_B) + P(L_A)\cdot P(T_B)$.

$= 0.75\times 0.20 + 0.25\times 0.80$

$= 0.15 + 0.20 = 0.35$.

$\therefore$ They contradict each other in $\boxed{35\%}$ of the cases.
