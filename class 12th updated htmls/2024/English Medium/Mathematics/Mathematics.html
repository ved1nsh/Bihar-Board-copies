Prove that sin⁻¹(4/5) + sin⁻¹(5/13) + sin⁻¹(16/65) = π/2.
Ans

Let A = sin⁻¹(4/5) and B = sin⁻¹(5/13).

sin A = 4/5 ⇒ cos A = 3/5 sin B = 5/13 ⇒ cos B = 12/13

Now find sin(A + B):

sin(A + B) = sin A cos B + cos A sin B = (4/5)(12/13) + (3/5)(5/13) = 48/65 + 15/65 = 63/65

So A + B = sin⁻¹(63/65). We must show this equals π/2 − sin⁻¹(16/65).

sin[π/2 − sin⁻¹(16/65)] = cos[sin⁻¹(16/65)] = √(1 − (16/65)²) = √((65² − 16²)/65²) = √((4225 − 256)/4225) = √(3969/4225) = 63/65

Since sin(A+B) = 63/65 = sin[π/2 − sin⁻¹(16/65)], we get:

sin⁻¹(4/5) + sin⁻¹(5/13) = π/2 − sin⁻¹(16/65) ∴ sin⁻¹(4/5) + sin⁻¹(5/13) + sin⁻¹(16/65) = π/2 (Proved)

Evaluate : ∫ from 0 to π/2 of log(cos x) dx.
Ans

Let I = ∫₀^(π/2) log(cos x) dx.

Using the property ∫₀^a f(x) dx = ∫₀^a f(a − x) dx with a = π/2 :

I = ∫₀^(π/2) log[cos(π/2 − x)] dx = ∫₀^(π/2) log(sin x) dx

Adding the two expressions for I :

2I = ∫₀^(π/2) [log(cos x) + log(sin x)] dx = ∫₀^(π/2) log(sin x cos x) dx = ∫₀^(π/2) log[(sin 2x)/2] dx = ∫₀^(π/2) log(sin 2x) dx − ∫₀^(π/2) log 2 dx

The first integral equals I (by substitution 2x = t), and the second is (π/2)·log 2 :

2I = I − (π/2) log 2 ⇒ I = −(π/2) log 2 (Ans.)

Solve : (1 + x²)(dy/dx) + y = tan⁻¹x.
Ans

Divide throughout by (1 + x²) to write it in linear form:

dy/dx + [1/(1+x²)]·y = (tan⁻¹x)/(1+x²)

This is linear: dy/dx + Py = Q, where P = 1/(1+x²), Q = (tan⁻¹x)/(1+x²).

I.F. = e^(∫P dx) = e^(∫dx/(1+x²)) = e^(tan⁻¹x)

Solution:

y·e^(tan⁻¹x) = ∫ e^(tan⁻¹x) · (tan⁻¹x)/(1+x²) dx + c

Put t = tan⁻¹x, so dt = dx/(1+x²):

= ∫ t·eᵗ dt + c = eᵗ(t − 1) + c = e^(tan⁻¹x)(tan⁻¹x − 1) + c
∴ y = (tan⁻¹x − 1) + c·e^(−tan⁻¹x) (Ans.)

5 marks
Find dy/dx when (sin y)ˣ = (cos x)ʸ.
Ans

Take log on both sides:

x · log(sin y) = y · log(cos x)

Differentiate both sides with respect to x:

x·(cos y/sin y)·(dy/dx) + log(sin y) = y·(−sin x/cos x) + log(cos x)·(dy/dx)
⇒ x cot y·(dy/dx) + log(sin y) = −y tan x + log(cos x)·(dy/dx)
⇒ (dy/dx)[x cot y − log(cos x)] = −y tan x − log(sin y)
∴ dy/dx = [y tan x + log(sin y)] / [log(cos x) − x cot y] (Ans.)
